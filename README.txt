Barbearia Navalha de Ouro

Integrantes: preencher com os nomes da equipe.

Como executar:
1. No MySQL Workbench, execute o arquivo banco.sql.
2. Confira usuário e senha do MySQL em barbearia/config.py.
3. Instale as dependências: pip install Flask mysql-connector-python
4. Na pasta do projeto, execute: python main.py
5. Abra http://127.0.0.1:5000 no navegador.
